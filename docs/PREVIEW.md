# 阅读预览工作台

参考 [Qiaomu Publish](https://github.com/joeseesun/qiaomu-publish/tree/4fbeae30017e1db4be95b7454620b30eae47ada8) 的预览交互：紧凑工具栏、居中纸面、按需展开排版设置、同步滚动与导出入口。实现沿用 AIWXEdit 的文章渲染、主题资源与公众号发布链路，未引入参考项目的主题包、中转服务器或浏览器扩展。

## 使用

- 工具栏左侧搜索现有文章主题，保留内置与用户已下载主题。
- 点击排版按钮展开字体、字号、配色与代码高亮；Escape 收起。
- 预览宽度可选手机 390px、桌面 768px 或适应面板。窄面板自动缩到可用宽度，不缩放文字。
- 更多菜单提供同步滚动、专注阅读、刷新、返回顶部和导出 HTML。专注阅读保留“显示工具栏”入口。
- 手机与桌面宽度是纸面外宽。纸面内保留 16px 阅读边距，复制和发布的文章根节点仍为零边距，不带工具栏、纸面容器或状态文字。
- 工具栏外观跟随 Obsidian，文章在 Shadow DOM 中显示同一份内联 HTML，避免宿主样式修改正文。主题背景延伸到纸面留白。
- 修改正文后约 180ms 更新预览；切换笔记和删除当前笔记会更新或清空预览。发布前保存源笔记，防止发送旧的磁盘内容。
- 同步滚动按两个面板可滚动距离的比例映射，只连接显示同一篇笔记的 Markdown 面板；不承诺代码折叠等情况下逐段精确对齐。

预览宽度、同步开关与专注阅读状态保存于插件设置。更改这些偏好不会改写笔记正文或文章主题。已有账号、样式与密钥字段不迁移到其他位置。

## HTML 导出

导出到库内 `AIWXEdit Exports/AIWXEdit-笔记名-时间.html`，重复导出生成新文件。内嵌库内 JPG、PNG、GIF、WebP、SVG 图片；不上传微信、不调用 AI。找不到附件、无法读取图片或遇到临时 blob 地址时停止导出并提示。远程图片保持原 URL，查看时仍需联网。复制和发布原有图片处理方式保持不变。

## 验证

`npm run test:preview` 检查旧设置兼容、偏好保存、中英文字数、阅读时长与滚动边界。

`node scripts/preview-workbench-smoke.mjs` 仅连接 19223 端口的独立 Obsidian 测试库，库名必须为 `AIWXEdit-QA`。验证主题搜索、宿主样式隔离、排版展开与键盘收起、双向滚动与禁用、编辑中刷新、零边距导出、真实 HTML 文件生成、本地图片内嵌、缺图错误、重复导出与专注阅读退出。设置 `AIWXEDIT_QA_OUTPUT` 可保存桌面深浅色与 390px 窄窗口截图和结果 JSON。测试不发送微信或 AI 请求，不等同于 iOS / Android 真机验收。

通用加载、危险 HTML、渲染竞态、关闭／重开及插件重载仍通过 `scripts/host-smoke.mjs` 验证。
