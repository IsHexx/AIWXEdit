# AIWXEdit 1.0.6

Prepare AIWXEdit for submission to the Obsidian Community directory.

- Sanitize article and AI HTML before rendering, including removing embedded pages and forms.
- Prevent older asynchronous previews from replacing the current note.
- Release preview subscriptions, state, and cached WeChat credentials when closing views or unloading the plugin.
- Register the publish view early so Obsidian can restore it on reload.
- Guard the desktop clipboard fallback on mobile.
- Remove MWeb styles and bundled download entries pending redistribution permission; existing installed styles are preserved.
- Add attribution and license text for the separate Markdown Nice styles.
- Upgrade vulnerable dependencies and add official Obsidian lint checks, version/asset validation, and a draft-only release workflow.
- Document network use, optional service charges, credential storage, and the community submission status.

Requires Obsidian 1.7.2 or later, reflecting the Workspace.revealLeaf API used by the plugin. Formula rendering is not implemented. Desktop smoke tests pass in Obsidian 1.14.5; mobile devices and real WeChat/AI operations have not been tested for this candidate.
